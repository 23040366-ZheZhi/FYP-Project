What is Pull function in Git?

Purpose: 
Used to update an existing local repository with changes from its associated remote repository.

Functionality: 
It fetches new commits from the remote and then automatically merges them into your current local branch. It is a combination of git fetch (downloads changes) and git merge (integrates changes).
